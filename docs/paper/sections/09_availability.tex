\section*{Data Availability and Reproducibility}

The experiments use one month of flight trajectories derived from EUROCONTROL's Aviation Data Repository for Research (ADRR)~\cite{eurocontrol_adrr_2025}. ADRR access is provided by EUROCONTROL for research and development use under its terms of use, but the raw data cannot be publicly redistributed by us. To support reproducibility, the project repository contains the end-to-end preprocessing script used to standardize ADRR data, configuration files for all reported runs, model implementations for all compared methods, experiment logs and evaluation summaries, and scripts for rebuilding development subsets and rerunning full experiments.
